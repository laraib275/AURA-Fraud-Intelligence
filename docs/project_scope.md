# AURA Project Scope

## Problem

Financial transaction systems can generate large numbers of alerts.
Investigators may need to manually correlate transactions, customer
behaviour, devices, IP addresses, merchants, and other evidence.

## Goal

Build an end-to-end AI-assisted fraud detection and investigation
platform.

## Core Components

1. Fraud Detection
2. Anomaly Detection
3. Behavioural Risk Analysis
4. Risk Scoring
5. Explainable AI
6. Graph Intelligence
7. Investigation Engine
8. Retrieval-Augmented Generation
9. AI Investigation Agent
10. Counterfactual Analysis
11. Uncertainty Estimation
12. Adversarial Fraud Simulation
13. Human-in-the-loop Feedback

## Project Philosophy

The system will be developed incrementally.

Each major capability will be experimentally evaluated before being
integrated into the final platform.
